# File Ownership Learnings:
- File ownership is devided into Owner, Group, Other users
- Changing the owner and group with <mark>chown owner:group file.name</mark> controls who can read/write/execute.
- Group ownership + setgid on directories ensure all new files inherit the correct group, critical for team collaboration in DevOps.
